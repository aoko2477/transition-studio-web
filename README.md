# Transition Studio Web

ブラウザだけでトランジション素材を作成・確認・書き出しできるWebツールです。CCFOLIA向けのOUT・HOLD・IN 3素材セットと、1MB・5MB以下を目標にしたAnimated WebPの容量自動最適化に対応しています。

## Web版を使う

公開ページ：<https://aoko2477.github.io/transition-studio-web/>

インストールや素材のアップロードは不要です。作成・検査・書き出し処理はブラウザ内で行われます。

## 主な機能

- フェード、ワイプ、スプリット、まばたき、アイリス、ストライプ、タイル、ラジアル、ズーム等のトランジション作成
- Animated WebP、APNG、PNG連番ZIPの書き出し
- CCFOLIA向けOUT・HOLD・IN 3素材セットの一括書き出し
- Animated WebPを1MB・5MB・任意容量以下へ収める自動探索
- 解像度、FPS、動作方向、透明度、補間曲線等の調整
- Animated WebP・APNGのフレーム検査、Safe Cut確認、トリム
- 設定JSONの保存・読み込み

WebMは現在選択できません。OBS向けの「入り → 保持 → 抜け」編集は利用できますが、透過WebMの書き出しはローカル版への実装を予定しています。

## 基本的な使い方

1. 「設定」でトランジション、動作、色、時間を選びます。
2. 中央のプレビューとシークバーで動きを確認します。
3. 右側の「書き出し」で形式、解像度、FPS、容量を選びます。
4. CCFOLIA用なら、既定の「3素材セット・Animated WebP（ZIP）」を選んだまま書き出します。
5. 必要に応じて「検査」へファイルをドラッグ＆ドロップし、各フレームを確認します。

## FPSの目安

- 30fps：標準。容量を抑えやすく、多くの用途に向きます。
- 60fps：動きがよりなめらかになりますが、フレーム数と容量が増えます。

1MB・5MB設定では、まず圧縮品質を調整します。「発展的：Web版でもFPS・画像サイズを探索」を有効にすると、選択した優先方針に応じてFPSや解像度も探索します。

## 対応環境

デスクトップ版の最新Google ChromeまたはMicrosoft Edgeを推奨します。大きな解像度、60fps、長時間のアニメーションは、端末のメモリや処理性能によって書き出しに時間がかかる場合があります。

## プライバシー

通常の作成、書き出し、検査では、選択した画像や生成フレームを外部サーバーへ送信しません。GitHub Pagesへのアクセスについては、GitHubのプライバシー方針が適用されます。

## ローカルで確認する

静的ファイルだけで動作します。リポジトリを取得後、次のようなHTTPサーバーで開けます。

```powershell
python -m http.server 8000
```

その後、<http://localhost:8000/>を開いてください。`index.html`の直接表示ではなく、HTTPサーバー経由を推奨します。

構文チェック：

```powershell
npm run check
```
